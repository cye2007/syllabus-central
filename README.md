# SyllaView

> Turn messy college syllabi into one clear, interactive academic command center.

SyllaView transforms static syllabus PDFs into an actionable semester hub. Upload your syllabi to get an aligned course comparison, an exportable deadline calendar, a live office hours tracker, and citations that link directly back to the original PDF pages.

---

## Features

- **AI Syllabus Extraction:** Upload PDFs to automatically extract courses, instructors, grading breakdowns, policies, and deadlines.
- **Side-by-Side Semester Overview:** Compare all your classes in an aligned column grid to review policies, meeting times, and grading at a glance.
- **Help Today Hub:** See which professors and TAs have office hours today, with live status badges and one-click email.
- **Unified Calendar & .ics Export:** Track all assignments and exams in one place, and export them directly to Google Calendar, Apple Calendar, or Outlook.
- **Source Verification:** Every extracted fact links back to its exact page in the syllabus PDF.
- **Conflict Detection:** Flags overlapping exam dates and missing grading criteria for manual review.

---

## Tech Stack

- **Frontend:** React 19, TanStack Start, Vite, Tailwind CSS
- **Backend:** Lovable Cloud (PostgreSQL, Auth, Storage)
- **AI:** Gemini via Lovable AI Gateway
- **Testing:** Vitest, Playwright
